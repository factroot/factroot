# FactRoot

منصة عربية للتحقق من الأخبار بمقارنتها بمنشورات حسابات حكومية موثوقة على X.

## المزايا الموجودة

- التحقق من الأخبار عبر X API.
- ثلاث محاولات للزائر، ثم يُطلب منه تسجيل الدخول.
- إنشاء حساب وتسجيل دخول وخروج بكلمات مرور مشفّرة.
- سجل خاص بعمليات المستخدم المسجّل.
- صلاحيات مستخدم ومدير.
- لوحة إدارة للمستخدمين والإحصائيات.
- إضافة وتفعيل وتعطيل مصادر X الموثوقة.
- عرض نشاط التحقق للمدير دون كشف نص الخبر.

## المتطلبات

- Node.js 20 أو أحدث.
- Python 3.11 أو أحدث.
- مفتاح X API يوضع محليًا ولا يُشارك مع الآخرين.

## التشغيل لأول مرة

من داخل مجلد المشروع ثبّتي مكتبات الواجهة:

```powershell
npm.cmd install
```

ثم ثبّتي مكتبات Python:

```powershell
py -m pip install -r requirements.txt
```

انسخي `backend/.env.example` باسم `backend/.env.local`، ثم ضعي قيمة
`X_BEARER_TOKEN` الخاصة بك داخل الملف الجديد.

## تشغيل الواجهة

```powershell
npm.cmd run dev -- --webpack
```

ثم افتحي `http://localhost:3000`.

## تشغيل الخلفية

من Terminal ثانية داخل مجلد المشروع:

```powershell
py -m uvicorn backend.main:app --reload
```

الخلفية تعمل على `http://localhost:8000`، وتُنشأ قاعدة البيانات المحلية
`backend/factroot.db` تلقائيًا عند أول تشغيل.

## إنشاء حساب المدير

من Terminal ثالثة داخل مجلد المشروع:

```powershell
py -m backend.create_admin
```

أدخلي اسم المدير وبريده وكلمة المرور. كتابة كلمة المرور لا تظهر على الشاشة، وهذا طبيعي.

## ملفات لا يجب مشاركتها

- `backend/.env.local` لأنه يحتوي مفتاح X السري.
- `backend/factroot.db` لأنها تحتوي الحسابات والسجل المحلي.
- مجلدا `node_modules` و`.next` لأنهما يُنشآن محليًا.

ملف `.gitignore` مضبوط لمنع إضافة هذه الملفات إلى Git مستقبلًا.

## النسخة المدمجة

التصميم والتنسيق من factroot، والوظائف والخلفية من FactRoot-SHARE-voice-accessibility.
تشمل الإملاء بالميكروفون، قراءة الخبر والنتيجة، الحسابات والسجل ولوحة الإدارة.
استخرج هذه النسخة في مجلد جديد ثم اتبع خطوات التشغيل أعلاه.
الإملاء الصوتي يعتمد على دعم المتصفح وإذن الميكروفون، والتحقق الفعلي يحتاج مفتاح X API صالحًا.
